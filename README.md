# Video Player

基于 **PyQt6 + Qt Multimedia** 的 Windows 桌面视频播放器。深色界面，支持播放列表树、书签、继续观看、历史记录、全局快捷键与系统托盘。

## 功能特性

- **多种加载方式**：打开单个/多个视频文件或整个文件夹，也支持直接拖放
- **目录树播放列表**：文件夹逐层展开/折叠，双击播放，支持拖拽排序、置顶、钉住、重命名
- **播放控制**：播放/暂停、上一个/下一个、点击/拖拽定位、0.25×–3.0× 倍速、音量调节
- **循环模式**：不循环 / 单曲循环 / 列表循环
- **书签**：`M` 键快速添加，单击跳转，进度条上显示三角标记，支持重命名、导出为 JSON 或 SRT 字幕
- **继续观看**：自动记录未看完的视频和进度，双击续播
- **已看/未看标记**：播放超过 90% 自动标记，列表中灰色打勾显示
- **位置记忆**：自动记忆并恢复每个视频的最后播放位置
- **会话恢复**：重启后自动恢复上次打开的播放列表（含文件夹展开状态）
- **历史记录**：记录所有加载过的文件/文件夹，支持置顶、钉住、拖拽排序
- **搜索**：`Ctrl+F` 或 `/` 快速过滤播放列表
- **截图**：`Ctrl+S` 截取当前画面保存为 PNG
- **全屏播放**：`F` 或双击画面切换；全屏时控制栏自动隐藏
- **系统托盘**：最小化到托盘，托盘菜单控制播放
- **全局快捷键**：可在任意程序前台时控制播放（需安装 `keyboard` 包）
- **每视频独立设置**：分别记住每个视频的倍速和音量

## 环境要求

- Python 3.10+（使用了 `X | Y` 类型标注语法）
- Windows 10/11（其余平台未测试，字体等细节可能需要调整）

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

> `keyboard` 为可选依赖：未安装时程序正常运行，只是全局快捷键（`Ctrl+Alt+Space` 等）不可用。

## 打包为 exe

```bash
python build.py
```

脚本会自动安装 PyInstaller / Pillow、生成图标并打包出 `dist\VideoPlayer.exe`。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `Shift+←` / `Shift+→` | 快退 / 快进 30 秒 |
| `↑` / `↓` | 音量 ±5 |
| `N` / `B` | 下一个 / 上一个 |
| `F` / 双击画面 | 全屏切换 |
| `Escape` | 退出全屏 |
| `M` | 添加书签 |
| `[` / `]` | 上一个 / 下一个书签 |
| `Alt+1` … `Alt+9` | 跳转到第 1–9 个书签 |
| `P` | 显示 / 隐藏侧边栏 |
| `Ctrl+F` 或 `/` | 搜索播放列表 |
| `Ctrl+S` | 截图 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+Shift+O` | 打开文件夹 |

全局快捷键（需安装 `keyboard` 包，任意前台程序下生效）：

| 按键 | 功能 |
| --- | --- |
| `Ctrl+Alt+Space` | 播放 / 暂停 |
| `Ctrl+Alt+→` | 下一个 |
| `Ctrl+Alt+←` | 上一个 |

## 数据存储

所有用户数据（书签、播放位置、历史记录、偏好设置等）保存在用户主目录下的 `~/.videoplayer_data.json`，程序启动时会自动清理文件已不存在的记录。

## 项目结构

```
main.py           # 全部应用代码（数据持久化、界面、托盘）
build.py          # PyInstaller 打包脚本
icon_gen.py       # 图标生成脚本
requirements.txt  # 运行依赖
launch.bat        # 开发运行（自动检查依赖）
build.bat         # 一键打包
```
